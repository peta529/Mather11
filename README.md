- У правому верхньому кутку є кнопка **«Увійти в акаунт адміна»** — після входу з'являються кнопки керування (додати/змінити/видалити товар, налаштування каталогу).

Пароль адміна вже вписаний у код (`lib/auth.js`): **Podium53001**
Окрему змінну середовища для пароля налаштовувати не потрібно.

Дані (назва каталогу, товари) і фотографії зберігаються у вбудованому файловому сховищі Vercel (Vercel Blob) — воно безкоштовне для такого невеликого каталогу.

## Крок 1. Встановіть інструменти (один раз)

1. Встановіть Node.js, якщо його ще немає: https://nodejs.org (версія LTS).
2. Встановіть Vercel CLI — у терміналі:
   ```
   npm install -g vercel
   ```

## Крок 2. Завантажте сайт на Vercel

1. Розпакуйте цей проєкт у папку на комп'ютері.
2. У терміналі перейдіть у цю папку (`cd шлях/до/папки`).
3. Виконайте:
   ```
   vercel
   ```
   Увійдіть у свій акаунт Vercel (якщо його немає — реєстрація безкоштовна) і відповідайте на питання за замовчуванням (Enter на кожне).

## Крок 3. Підключіть сховище файлів (Vercel Blob)

1. Зайдіть у панель керування на vercel.com → відкрийте свій проєкт.
2. Перейдіть у вкладку **Storage** → **Create Database** → виберіть **Blob**.
3. Access mode виберіть **Public**, натисніть створити й підключити до проєкту (Connect to Project).

## Крок 4. Задеплойте ще раз, щоб сховище підключилось

```
vercel --prod
```

## Готово 🎉

Відкрийте `https://ваш-проєкт.vercel.app` — одразу видно каталог. Натисніть «Увійти в акаунт адміна» у верхньому правому кутку, введіть пароль **Podium53001** — з'являться кнопки керування.

При першому вході попросить заповнити назву каталогу, короткий опис і, за бажанням, посилання для звʼязку (WhatsApp/Telegram). Далі просто тиснете «+ Додати товар» унизу справа.

## Якщо потрібно щось змінити пізніше

- **Змінити пароль** — відкрийте файл `lib/auth.js`, замініть рядок `const ADMIN_PASSWORD = 'Podium53001';` на свій пароль, потім `vercel --prod` ще раз.
- Змінити назву каталогу, опис чи контакт — кнопка «Налаштування» у шапці сайту (після входу).
- Дизайн, кольори, тексти — попросіть Клода змінити код і надішліть оновлені файли.

## Важливо про пароль у коді

Пароль зберігається просто текстом у файлі `lib/auth.js` на сервері — його не видно у браузері й звичайні відвідувачі його ніяк не побачать. Але якщо коли-небудь викладете код у публічний GitHub-репозиторій, пароль стане видно всім, хто відкриє файл. Для сімейного каталогу це не критично, але майте на увазі.
